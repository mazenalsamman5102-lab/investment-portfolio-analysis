Investment Portfolio Analysis
Overview

This academic project was developed as part of a Portfolio Management course. The project focuses on analyzing a portfolio of selected Saudi-listed companies using historical stock price data and applying fundamental investment analysis concepts.

Objectives
Calculate stock returns using historical market data.
Analyze portfolio performance and compare it with market performance.
Apply portfolio management concepts such as diversification and risk-return analysis.
Evaluate the statistical distribution of returns using Gretl.
Tools Used
Microsoft Excel
Gretl
Project Activities
Collected and organized historical stock price data for selected Saudi companies.
Calculated periodic stock returns and market returns.
Analyzed portfolio performance using financial and statistical techniques.
Conducted a normality test on stock returns using Gretl.
Interpreted results to better understand return behavior and investment performance.
Key Learning Outcomes
Improved practical skills in investment and portfolio analysis.
Enhanced understanding of risk and return relationships.
Applied statistical analysis techniques in financial decision-making.
Gained experience using Excel and Gretl for financial data analysis.
Disclaimer

This project was completed for academic purposes as part of university coursework and is intended to demonstrate financial analysis and portfolio management skills
